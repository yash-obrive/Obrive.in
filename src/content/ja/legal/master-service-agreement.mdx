    Obrive Industries マスターサービス契約（MSA）は、AR、VR、MR、XR、3Dデザイン、および空間コンピューティングにおける当社の没入型ソリューションを提供するための枠組みを定義します。
  </CompanyInfoItem>
</CompanyInfoSection>

<CompanyInfoSection>
  <CompanyInfoItem title="主なハイライト:">
    <br />
    <ul>
      <li>
        サービスの範囲：プロジェクトの成果物、タイムライン、および没入型技術の導入を概説します。
      </li>
      <li>
        料金と支払い：支払い条件、更新、および請求書の構成を定義します。
      </li>
      <li>
        知的財産権：クライアントは自分のコンテンツの所有権を保持し、Obriveはプラットフォームの知的財産権を保持します。
      </li>
      <li>
        機密保持: 敏感なビジネスおよびプロジェクト情報の相互保護。
      </li>
      <li>
        サポートと保証：サービスレベル、稼働時間、および技術サポートの約束。
      </li>
      <li>
        終了：いずれの当事者も契約を終了できる条件。
      </li>
    </ul>
    <br />
    この契約は、長期的な没入型技術パートナーシップにおける明確さ、説明責任、信頼を確保します。
  </CompanyInfoItem>
</CompanyInfoSection>

<CompanyInfoSection title="詳細なマスターサービス契約（MSA）">
  <CompanyInfoItem>
    本マスターサービス契約（MSA）は、Obrive Industries Pvt. Ltd.（以下「Obrive」、「当社」または「私たち」）とそのクライアント（以下「クライアント」、「あなた」または「あなたの」）との間で、AR、VR、MR、XR、3Dデザイン、および空間コンピューティングソリューションを含む没入型技術サービスに関する関係を規律するものです。
  </CompanyInfoItem>
</CompanyInfoSection>
<CompanyInfoSection title="1. サービスの範囲">
  <CompanyInfoItem>
    <ul>
      <li>
        Obriveは、作業指示書（SOW）で合意された通り、没入型製品、アプリケーション、および専門サービスを提供します。
      </li>
      <li>
        各SOWは、プロジェクトの成果物、マイルストーン、受け入れ基準、および展開のタイムラインを定義します。
      </li>
      <li>
        サービスには、コンサルティング、3Dモデリング、アプリケーション開発、統合、トレーニング、技術サポートが含まれる場合があります。
      </li>
    </ul>
  </CompanyInfoItem>
</CompanyInfoSection>

<CompanyInfoSection title="2. 料金と支払い">
  <CompanyInfoItem>
    <ul>
      <li>料金は、それぞれのSOWまたは注文書に記載されます。</li>
      <li>
        支払条件：通常、請求書の日付から10日以内。ただし、特に記載がある場合を除く。
      </li>
      <li>支払いが遅れると、サービスの停止や利息が発生する可能性があります。</li>
      <li>
        定期的なサービス（ホスティング、サポート、メンテナンス）は、サブスクリプション方式で請求されます。
      </li>
    </ul>
  </CompanyInfoItem>
</CompanyInfoSection>

<CompanyInfoSection title="3. 知的財産権">
  <CompanyInfoItem>
    <ul>
      <li>
        クライアントコンテンツ：クライアントは、提供するすべての専有データ、モデル、資産の所有権を保持します。
      </li>
      <li>
        Obriveの知的財産権: Obriveは、その没入型プラットフォーム、事前構築モジュール、SDK、API、およびフレームワークの所有権を保持します。
      </li>
      <li>
        カスタム成果物：別段の合意がない限り、カスタム開発はクライアントに対して内部使用のための非独占的、譲渡不可のライセンスを付与する場合があります。
      </li>
    </ul>
  </CompanyInfoItem>
</CompanyInfoSection>

<CompanyInfoSection title="4. 機密保持">
  <CompanyInfoItem>
    <ul>
      <li>
        両当事者は、機密性の高い事業上、財務上、技術上の情報の機密を保持することに同意します。
      </li>
      <li>
        秘密情報は、法令で要求される場合を除き、書面による同意なしに第三者に開示してはなりません。
      </li>
      <li>
        機密保持義務は、契約終了後も3年間存続します。
      </li>
    </ul>
  </CompanyInfoItem>
</CompanyInfoSection>

<CompanyInfoSection title="5. データ保護とセキュリティ">
  <CompanyInfoItem>
    <ul>
      <li>
        Obriveは、業界標準のデータ保護対策（暗号化、アクセス制御、バックアップ）を実施しています。
      </li>
      <li>
        必要に応じて、適用されるデータ保護規制（GDPR、CCPAなど）を遵守すること。
      </li>
      <li>
        クライアントは、Obriveシステム内で自分のデータを合法的に使用することを確実にする責任を負い続けます。
      </li>
    </ul>
  </CompanyInfoItem>
</CompanyInfoSection>

<CompanyInfoSection title="6. 保証と免責事項">
  <CompanyInfoItem>
    <ul>
      <li>
        オブリーブは、サービスが業界標準に沿った専門的な方法で実施されることを保証します。
      </li>
      <li>
        サービスが中断されないことや、エラーがないことを保証するものではありません。
      </li>
      <li>
        Obriveの管理外のサードパーティの統合に関しての責任を否認します。
      </li>
    </ul>
  </CompanyInfoItem>
</CompanyInfoSection>

<CompanyInfoSection title="7. サポートとサービスレベル">
  <CompanyInfoItem>
    <ul>
      <li>
        Obriveは、SOWまたはサービスレベル契約（SLA）に記載されている通りに技術サポートを提供します。
      </li>
      <li>バグ修正、アップデート、定期的な機能強化が含まれます。</li>
      <li>対応時間は、問題の重大性と影響に応じて異なります。</li>
    </ul>
  </CompanyInfoItem>
</CompanyInfoSection>

<CompanyInfoSection title="8. 期間および終了">
  <CompanyInfoItem>
    <ul>
      <li>MSAは、いずれかの当事者によって終了されるまで有効です。</li>
      <li>
        いずれの当事者も、都合により30日間の書面による通知で契約を終了することができます。
      </li>
      <li>
        違反、支払い不能、または未払いの場合、即時解約が許可されます。
      </li>
      <li>
        契約終了時、クライアントはObriveの技術の使用を中止し、未払いの支払いを清算しなければなりません。
      </li>
    </ul>
  </CompanyInfoItem>
</CompanyInfoSection>

<CompanyInfoSection title="9. 責任および補償">
  <CompanyInfoItem>
    <ul>
      <li>
        Obriveの責任は、過去12か月間にクライアントが支払った金額に限定されます。
      </li>
      <li>
        いずれの当事者も、間接的、偶発的、または結果的損害について責任を負いません。
      </li>
      <li>
        各当事者は、誤用、知的財産権の侵害、または違反により生じた第三者の請求に対して、相手方を補償することに同意します。
      </li>
    </ul>
  </CompanyInfoItem>
</CompanyInfoSection>

<CompanyInfoSection title="10. 準拠法および紛争解決">
  <CompanyInfoItem>
    <ul>
      <li>
        本契約は、オブリーブが本社を置く法域の法律に従って規律されるものとします。
      </li>
      <li>
        紛争はまず善意の交渉によって解決されます。それが不調に終わった場合、拘束力のある仲裁または管轄裁判所が適用されます。
      </li>
    </ul>
  </CompanyInfoItem>
</CompanyInfoSection>

<CompanyInfoSection title="11. 雑項">
  <CompanyInfoItem>
    <ul>
      <li>
        完全合意：本MSAおよびいかなるSOWも、本契約の全合意を表します。
      </li>
      <li>
        修正: 変更は書面で行い、両当事者が署名する必要があります。
      </li>
      <li>
        譲渡: いずれの当事者も、事前の書面による同意なしに本契約を譲渡することはできません。
      </li>
    </ul>
  </CompanyInfoItem>
</CompanyInfoSection>

<CompanyInfoSection title="アクセシビリティをサポートする方法">
<CompanyInfoItem title="1. 支援技術の互換性">
<ul>
            <li>
              私たちのウェブプラットフォームやポータルは、スクリーンリーダー、音声認識ツール、代替ナビゲーションデバイスに対応しています。
            </li>
            <li>
              VRおよびARの体験は、可能な場合にオーディオ説明、字幕、調整可能なインターフェースを備えて設計されています。
            </li>
          </ul>
</CompanyInfoItem>

<CompanyInfoItem title="2. 包括的な没入型デザイン">
  <ul>
    <li>
      Obmoveでの動作およびジェスチャーに基づく操作には、身体の可動域が制限されているユーザー向けの代替手段が含まれています。
    </li>
    <li>ObnaviのARナビゲーションは、複数の感覚に訴えるヒント（視覚＋聴覚）を提供します。</li>
    <li>
      ObnestのVR環境は、簡易ナビゲーションやガイド付きモードで設定することができます。
    </li>
  </ul>
</CompanyInfoItem>

<CompanyInfoItem title="3. カスタマイズ可能なユーザー体験">
  <ul>
    <li>
      テキストの拡大、ハイコントラストモード、ハプティックフィードバック、キャプションのオプション。
    </li>
    <li>ユーザーの設定は、セッション間で一貫性を保つために保存されます。</li>
  </ul>
</CompanyInfoItem>

<CompanyInfoItem title="4. 継続的なテストとフィードバック">
<ul>
            <li>
              ウェブ、AR/VRポータル、および空間アプリ全体で定期的にアクセシビリティ監査が行われています。
            </li>
            <li>
              私たちはユーザーのフィードバックを求めて、障壁を特定し、アクセシビリティ機能を改善します。
            </li>
          </ul>
</CompanyInfoItem>
</CompanyInfoSection>

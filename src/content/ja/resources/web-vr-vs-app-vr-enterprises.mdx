<WhyItWorkedSection title="Web VR がそれを変えるまで、VR はアプリがすべてだと常に思っていました">
  <WhyItWorkedItem>

    <br />

  </WhyItWorkedItem>
</WhyItWorkedSection>

    </ul>
    <br />
    Web VR バージョンはシームレスなアクセス性を提供しました：ステークホルダーは複数のデバイスで瞬時に参加できました。一方、ネイティブアプリは驚くほど美しいビジュアルと正確な操作を提供しました。 <br />
    どちらも感銘を受けた—しかし理由は異なる。そのバランスが、企業レベルの意思決定の旅を促した
  </WhyItWorkedItem>

<WhyItWorkedSection title="Web VR を選択する場合とネイティブに移行する場合">
  <WhyItWorkedItem>
    <StyledText>Web VR が輝くのは次の場合です:</StyledText>
    <br />
    <ul>
      <li> 市場へのスピードが重要です—リンクやQRで共有すれば、すぐに公開されます。</li>
      <li> 開発負担なしでクロスプラットフォームのリーチが必要です。</li>
      <li>
        あなたは軽いVRを目指します：製品プレビュー、ウォークスルー、頻繁な更新。
      </li>
    </ul>
    <br />
    <StyledText>しかし、ネイティブアプリVRが勝つのは次の場合です：</StyledText>
    <br />
    <ul>
      <li>
        現実性が必要です―高度なトラッキング、SLAM、または高精細なインタラクション。
      </li>
      <li>
        ユースケースは、オフラインでの安定性、複雑な環境、または頑丈なハードウェアを求めます。
      </li>
    </ul>
  </WhyItWorkedItem>
</WhyItWorkedSection>

<WhyItWorkedSection title="バズを超えて: 両方の道が重要な理由">
  <WhyItWorkedItem>
    Web VRはアプリベースのVRを置き換えることではなく、参入のハードルを下げることに関するものです。あなたは <StyledText>没入型を開始</StyledText> Web VR を使用し、その後、強力なネイティブ VR ビルドを通じてエンゲージメントを深める。
    <br />
    <br />
    オブリーブでは、それが私たちの二重トラック戦略です：初期段階では即時Web VRを展開し、その後、拡張可能な企業向けアプリケーションのためにカスタマイズされたApp VRに移行します。
  </WhyItWorkedItem>
</WhyItWorkedSection>

<WhyItWorkedSection title="次に控えているものは何か">
  <WhyItWorkedItem>
    <ul>
      <li>
        As <StyledText>WebXR標準が成熟する</StyledText>, より複雑なVR機能がブラウザ対応になるでしょう。
      </li>
      <li>
        新興の <StyledText>5Gとエッジコンピューティング</StyledText> ブラウザベースのVRのストリーミング精度を向上させます。
      </li>
      <li>
        <StyledText>ハイブリッドフレームワーク</StyledText> (Unity、Babylon.js) は境界線を曖昧にしている――一度のビルドで、複数のプラットフォームに対応できる。
      </li>
      <li>
        コラボレーション対応の「VR対応」ソリューションは、モバイル、デスクトップ、VRをサポートし、リーチを最大化します
      </li>
    </ul>
  </WhyItWorkedItem>
</WhyItWorkedSection>

<WhyItWorkedSection title="結論：かっこいいものだけでなく、意味のあるものを選びましょう">
  <WhyItWorkedItem>
    Web VRとApp VRのどちらかを選ぶことは二者択一ではありません。それは戦略的な選択です。
    <br />
    <ul>
      <li>Web VRは、敏捷性、アクセスしやすさ、そして速度を提供します。</li>
      <li>App VRは精度、深さ、そして没入型の力を提供します。</li>
    </ul>
    <br />
    あなたの企業のユースケースにどれが適しているか迷っていますか？今そしてこれからに適した没入型の道筋を共に設計しましょう。
  </WhyItWorkedItem>
</WhyItWorkedSection>

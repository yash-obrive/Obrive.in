<CareerSection title="이 역할에 대하여">
<CareerItem>3D 시각화 디자이너로서, 여러분은 AR, VR, MR 및 공간 컴퓨팅 경험 전반에서 몰입형 플랫폼에 생명을 불어넣는 실감 나는 포토리얼리스틱 3D 모델과 환경을 제작하게 됩니다. 여러분의 작업은 주요 제품인 Obpark(AR 내비게이션)과 Obnest(XR 홈 투어)와 같은 핵심 제품의 중심이 될 것입니다.</CareerItem>

<CareerItem title="당신이 할 일">
  <ul>
    <li>몰입형 애플리케이션을 위해 매우 상세한 3D 자산을 제작합니다.</li>
    <li>
현실적인 건축 시각화, 제품 프로토타입을 만들고
대화 형 AR/VR 연습.
    </li>
    <li>
개발자, UX/UI 디자이너 및 제품 전략가와 협력하여
3D 모델을 실제 경험에 통합하십시오.
    </li>
    <li>
시각적 충실도와 실시간 성능의 균형을 맞추기 위해 자산 최적화
여러 장치에서.
    </li>
    <li>
질감, 조명 및 조명을 통해 시각적 미학과 혁신을 촉진합니다.
동적 모델링.
    </li>
  </ul>
</CareerItem>

    </li>

렌더링.
    </li>
    <li>AR, VR, MR 플랫폼에 대한 자산 최적화 경험.</li>
    <li>
세부 사항에 대한 탁월한 주의력과 시각적 스토리텔링에 대한 열정
몰입 형 디자인을 통해.
    </li>
  </ul>
</CareerItem>

<CareerSection title="Об этой роли">
<CareerItem>Как дизайнер 3D-визуализации, вы будете создавать реалистичные, фотореалистичные 3D-модели и среды, которые оживят наши иммерсивные платформы-в AR, VR, MR и пространственных вычислениях. Ваша работа будет иметь центральное значение для флагманских продуктов, таких как Obpark (AR-навигация) и Obnest (домашние туры XR).</CareerItem>

<CareerItem title="Что ты будешь делать">
  <ul>
    <li>Создавайте высоко детализированные 3D-объекты для иммерсивных приложений.</li>
    <li>
Создавайте реалистичные архитектурные визуализации, прототипы продуктов и
интерактивные AR/VR-экскурсии.
    </li>
    <li>
Сотрудничайте с разработчиками, UX/UI-дизайнерами и стратегами по продуктам для
Интегрируйте 3D-модели в реальный мир.
    </li>
    <li>
Оптимизируйте ресурсы, чтобы сбалансировать визуальную точность с производительностью в реальном времени
на разных устройствах.
    </li>
    <li>
Подтолкнуть визуальную эстетику и инновации с помощью текстур, освещения и
динамическое моделирование.
    </li>
  </ul>
</CareerItem>

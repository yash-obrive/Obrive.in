<WhyItWorkedSection title="Att välja rätt verktyg för ditt mål">
  <WhyItWorkedItem>
    <StyledText>Use AR when you want:</StyledText>
    <ul>
      <li>
Omedelbar engagemang via mobilen-tänk WebAR skannar, interaktiva förpackningar,
eller AR-aktiverade broschyrer. Dina läsare kan kolla in vår
        <StyledText>AR Printing</StyledText> and{" "}
        <StyledText>AR Presentations</StyledText> blogs for practical
inspiration.
      </li>
    </ul>
    <br />
    <StyledText>Go for VR when you need:</StyledText>
    <ul>
      <li>
Fullständig immersion—som virtuella rundturer eller träningssimuleringar som lämnar inget
distraktion utanför headsetet.
      </li>
    </ul>
    <br />
    <StyledText>Opt for MR when:</StyledText>
    <ul>
      <li>
Interaktion mellan verkliga och virtuella frågor-tänk rumsligt förankrat
workshops, designgranskningar eller live-samarbete.
      </li>
    </ul>
  </WhyItWorkedItem>
</WhyItWorkedSection>

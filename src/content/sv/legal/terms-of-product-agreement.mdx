Obrive Industries villkor för produkter avtalet beskriver reglerna
för att använda våra uppslukande plattformar:
<br />
<br />
<ul>
            <li>Obpark — AR/MR-based parking and navigation app.</li>
            <li>
Obnest — MR/VR fastighetsnavigerings- och visualiseringsplattform.
            </li>
            <li>
Obnavi — Spatial AR-navigeringssystem för inomhus/utomhus
miljöer.
            </li>
            <li>
Obmove-rörelse, gest och XR-baserade interaktiva lösningar.
            </li>
          </ul>
</CompanyInfoItem>

<CompanyInfoItem title="Viktiga Höjdpunkter:">
<br />
<ul>
            <li>
Användningsrättigheter: Kunder får en licens att använda Obrive-produkter som
beskrivs i kontrakt.
            </li>
            <li>
Begränsningar: ingen återförsäljning, omvänd teknik eller obehörig
distribution.
            </li>
            <li>
Data & säkerhet: kunder förblir ansvariga för uppladdade data;
Obrive skyddar plattformens säkerhet.
            </li>
            <li>
Uppdateringar och Support: Obrive ger uppdateringar, buggfixar och
teknisk support per prenumerationsvillkor.
            </li>
            <li>
Uppsägning: Åtkomst kan stängas av om villkoren bryts eller
avtal upphör.
            </li>
          </ul>
<br />
Dessa produktspecifika villkor säkerställer tydlighet, efterlevnad och smidig drift över
industrier som använder Obrive-teknik.
</CompanyInfoItem>
</CompanyInfoSection>

<CompanyInfoSection title="Detaljerade villkor för Produktavtal">
<CompanyInfoItem>
Detta avtal om produktvillkor reglerar användningen av Obrive Industries’
immersiva teknologiplattformar och lösningar, inklusive Obpark,
Obnest, Obnavi och Obmove.
</CompanyInfoItem>

<CompanyInfoItem title="1. Avtalets omfattning">
Detta avtal gäller specifikt för varje produkt under Obrive
Industri. Genom att använda våra plattformar samtycker du till att följa dessa
produktspecifika villkor tillsammans med vårt Master serviceavtal.
</CompanyInfoItem>
</CompanyInfoSection>

<CompanyInfoSection title="Villkor För Användning Av Produkter">
<CompanyInfoItem title="a. Obpark (AR/MR Parkeringsnavigeringsapp)">
<ul>
            <li>
Designad för parkeringshantering, navigering och smart mobilitet.
            </li>
            <li>
Kunder kan distribuera Obpark för intern verksamhet, kundinriktad
tjänster eller företagsintegration.
            </li>
            <li>
Begränsad från att återanvändas för orelaterade industrier (t.ex.,
återförsäljning som en separat app).
            </li>
          </ul>
</CompanyInfoItem>

<CompanyInfoItem title="B. Obnest (MR / VR Navigationsplattform för fastigheter)">
  <ul>
    <li>
Möjliggör fördjupande fastighetsgenomgångar, arkitektonisk visualisering och
kundpresentationer.
    </li>
    <li>
Licensierad för användning av fastighetsutvecklare, mäklare och fastigheter
Manager.
    </li>
    <li>
Kunder måste se till att uppladdade 3D-tillgångar, planritningar och innehåll är
lagligt ägd/licensierad.
    </li>
  </ul>
</CompanyInfoItem>

<CompanyInfoItem title="C. Obnavi (rumsligt ar-Navigationssystem)">
  <ul>
    <li>
Erbjuder inomhus-/utomhus-AR-navigeringslager för campus, köpcentrum,
flygplatser och tillverkningsanläggningar.
    </li>
    <li>
Tillåtet för användning som en del av företagssystem eller kundtjänster.
    </li>
    <li>
Förbjudet att använda i applikationer som involverar allmän säkerhet utan föregående
Obrive godkännande.
    </li>
  </ul>
</CompanyInfoItem>

<CompanyInfoItem title="d. Obmove (Rörelse/XR Interaktionsplattform)">
<ul>
            <li>
Erbjuder gestbaserade kontroller, XR-träning och rörelse
simulationer.
            </li>
            <li>
Licensierad för träning, utbildning och företagsproduktivitet
fall.
            </li>
            <li>
Inte tillåtet för militär eller försvarsrelaterad användning såvida inte
uttryckligen kontrakterad.
            </li>
          </ul>
</CompanyInfoItem>
</CompanyInfoSection>

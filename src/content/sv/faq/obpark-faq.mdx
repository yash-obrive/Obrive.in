<FAQAccordionSection title="Allmän information">
  <FAQItem question="What is Obpark?">
Obpark är ett AR/MR-drivet smart parkeringsnavigeringssystem utformat för att göra
parkering sömlös för förare samtidigt som företag kan optimera utrymme,
öka intäkterna och leverera en premiumupplevelse.
  </FAQItem>
  <FAQItem question="Who is Obpark designed for?">
Obpark tjänar köpcentrum, flygplatser, sjukhus, tunnelbana- och järnvägsstationer,
företagskontor, bostadslägenheter och gated communities.
  </FAQItem>
  <FAQItem question="How does Obpark benefit businesses?">
Det hjälper dig att maximera utnyttjandet av utrymme, generera nya intäktsströmmar,
förbättra kundnöjdheten och få datadrivna insikter i
verksamhet.
  </FAQItem>
</FAQAccordionSection>

<FAQAccordionSection title="Plattform Funktioner">
  <FAQItem question="What are the core features of Obpark?">
    <ul>
      <li>AR/MR navigation overlays for seamless guidance.</li>
      <li>QR code integration for instant mobile access.</li>
      <li>Smart parking spot reservation system.</li>
      <li>Value-added services like valet, EV charging, and car washing.</li>
      <li>Promotional pop-ups for in-app marketing.</li>
      <li>Safety & emergency features with real-time alerts.</li>
    </ul>
  </FAQItem>
  <FAQItem question="Does Obpark provide real-time data?">
Ja, Obpark tillhandahåller en live-instrumentpanel med beläggning, användningsanalys och
kundbeteende insikter.
  </FAQItem>
</FAQAccordionSection>

<FAQAccordionSection title="Installationsinformation">
  <FAQItem question="How is Obpark installed in a facility?">
    <ul>
      <li>Step 1: On-site assessment and mapping of your parking facility.</li>
      <li>
Steg 2: utplacering av AR/MR-rumsliga ankare, fyrar och QR-koder.
      </li>
      <li>
Steg 3: Integration med befintliga parkeringshanterings-/biljettsystem.
      </li>
      <li>Step 4: Driver access via the Obpark mobile app.</li>
      <li>Step 5: Setup of dashboards for monitoring and analytics.</li>
    </ul>
  </FAQItem>
  <FAQItem question="Does installation disrupt current operations?">
Nej. Installationen är utformad för att vara störningsfri och integreras smidigt med
befintliga system.
  </FAQItem>
  <FAQItem question="What support is provided during installation?">
Vi erbjuder heltäckande introduktion, personalutbildning och support dygnet runt
efter installationen.
  </FAQItem>
</FAQAccordionSection>

<FAQAccordionSection title="Produktprissättning">
  <FAQItem question="How is Obpark priced?">
Obparks prissättning beror på:
    <ul>
      <li>Facility size (number of parking spots & floors).</li>
      <li>Integration requirements with existing systems.</li>
      <li>Additional features (marketplace, EV charging, valet).</li>
    </ul>
  </FAQItem>
  <FAQItem question="Is pricing subscription-based or one-time?">
Vi erbjuder flexibla prismodeller:
    <ul>
      <li>One-time installation + annual maintenance.</li>
      <li>Or a subscription model based on facility size and active users.</li>
    </ul>
  </FAQItem>
  <FAQItem question="Can businesses get a custom quote?">
Ja. Varje anläggning är unik—företag kan begära ett skräddarsytt förslag
baserat på område, kapacitet och nödvändiga funktioner.
  </FAQItem>
</FAQAccordionSection>

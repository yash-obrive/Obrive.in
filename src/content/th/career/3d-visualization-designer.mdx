<CareerSection title="เกี่ยวกับบทบาทนี้">
<CareerItem>ในฐานะนักออกแบบภาพสามมิติ (3D Visualization Designer) คุณจะสร้างโมเดลและสภาพแวดล้อมสามมิติที่เหมือนจริงและมีความสมจริงเหมือนภาพถ่าย ซึ่งช่วยทำให้แพลตฟอร์มเสมือนจริงของเรามีชีวิต—ทั้งในประสบการณ์ AR, VR, MR และการประมวลผลเชิงพื้นที่ งานของคุณจะเป็นหัวใจสำคัญของผลิตภัณฑ์ชั้นนำเช่น Obpark (การนำทาง AR) และ Obnest (ทัวร์บ้าน XR)</CareerItem>

<CareerItem title="สิ่งที่คุณจะทำ">
  <ul>
    <li>สร้างสินทรัพย์ 3 มิติที่มีรายละเอียดสูงสำหรับแอปพลิเคชันเชิงโต้ตอบ</li>
    <li>
      สร้างภาพจำลองสถาปัตยกรรมที่สมจริง ต้นแบบผลิตภัณฑ์ และการเดินชมแบบโต้ตอบ AR/VR
    </li>
    <li>
      ทำงานร่วมกับนักพัฒนา นักออกแบบ UX/UI และนักวางกลยุทธ์ผลิตภัณฑ์เพื่อรวมโมเดล 3 มิติเข้ากับประสบการณ์ในโลกจริง
    </li>
    <li>
      ปรับแต่งสินทรัพย์เพื่อสร้างสมดุลระหว่างความสมจริงของภาพกับประสิทธิภาพแบบเรียลไทม์ในอุปกรณ์ต่าง ๆ
    </li>
    <li>
      ผลักดันความงามทางภาพและนวัตกรรมผ่านพื้นผิว แสง และ
การสร้างแบบจําลองแบบไดนามิก
    </li>
  </ul>
</CareerItem>

<CareerItem title="เกี่ยวกับคุณ">
  <ul>
    <li>
      เชี่ยวชาญกับเครื่องมือ 3D เช่น Blender, Maya, 3ds Max หรือ Cinema 4D
    </li>
    <li>
      ความเข้าใจอย่างลึกซึ้งเกี่ยวกับการเรนเดอร์แบบโฟโตรีลิสติก (PBR), ระบบแสงสว่าง และกระบวนการทำงานกับพื้นผิว
    </li>
    <li>
      ผลงานที่แสดงถึงการสร้างภาพสามมิติแบบดื่มด่ำหรือการเรนเดอร์สถาปัตยกรรม
    </li>
    <li>มีประสบการณ์ในการปรับแต่งทรัพย์สินสำหรับแพลตฟอร์ม AR, VR หรือ MR</li>
    <li>
      ใส่ใจในรายละเอียดอย่างยอดเยี่ยมและมีความหลงใหลในการเล่าเรื่องด้วยภาพผ่านการออกแบบที่ดื่มด่ำ
    </li>
  </ul>
</CareerItem>

<CareerItem title="ทำไมต้องเข้าร่วม OBRIVE?">
  <ul>
    <li>
      สร้างอนาคต: สร้างภาพสำหรับผลิตภัณฑ์เสมือนจริงล้ำสมัยในหลากหลายอุตสาหกรรม
    </li>
    <li>
      พื้นที่ทำงานร่วมกัน: ทำงานภายในทีมที่มุ่งเน้นการเติบโต ซึ่งผสมผสานการออกแบบ เทคโนโลยี และความคิดสร้างสรรค์
    </li>
    <li>
      วัฒนธรรมที่ยืดหยุ่น: แนวทางการทำงานระยะไกลเป็นหลักพร้อมโอกาสในการร่วมงานแบบพบหน้าในบังกาลอร์
    </li>
    <li>
      การเติบโตทางด้านอาชีพ: การทบทวนการออกแบบเป็นประจำ เวิร์กช็อป และการสำรวจความคิดสร้างสรรค์ที่ได้รับทุนสนับสนุนโดย Obrive
    </li>
  </ul>
</CareerItem>

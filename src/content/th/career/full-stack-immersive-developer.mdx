<CareerSection title="เกี่ยวกับบทบาทนี้">
<CareerItem>ในฐานะนักพัฒนาระบบครบวงจรแบบเข้มข้นที่ Obrive Industries คุณจะออกแบบและสร้างแอปพลิเคชันตั้งแต่ต้นจนจบที่สนับสนุนผลิตภัณฑ์เชิงประสบการณ์ของเรา ครอบคลุม AR, VR, MR, การออกแบบ 3 มิติ และการประมวลผลเชิงพื้นที่ ตั้งแต่ส่วนต่อประสานผู้ใช้ด้านหน้าแบบใช้งานง่ายจนถึงสถาปัตยกรรมด้านหลังที่สามารถขยายตัวได้ คุณจะมั่นใจได้ถึงประสิทธิภาพที่ราบรื่นในทุกอุปกรณ์และแพลตฟอร์ม</CareerItem>

<CareerItem title="สิ่งที่คุณจะทำ">
  <ul>
    <li>
      สร้างประสบการณ์ส่วนหน้าที่ดื่มด่ำโดยใช้ Unity, Unreal Engine, WebXR, หรือ Three.js
    </li>
    <li>
      พัฒนาระบบแบ็กเอนด์ที่ปรับขนาดได้เพื่อจัดการข้อมูลเชิงพื้นที่แบบเรียลไทม์และสินทรัพย์ 3 มิติ
    </li>
    <li>
      ทำงานร่วมกับนักออกแบบ วิศวกร และศิลปิน 3D เพื่อส่งมอบแอปพลิเคชัน AR/VR/MR
    </li>
    <li>ปรับปรุงประสิทธิภาพของแอปพลิเคชันสำหรับเว็บ มือถือ และชุดหูฟัง XR</li>
    <li>
      รักษาโค้ดที่สะอาดและนำกลับมาใช้ใหม่ได้ด้วยท่อ CI/CD และเวิร์กโฟลว์แบบ Agile
    </li>
  </ul>
</CareerItem>

<CareerItem title="เกี่ยวกับคุณ">
  <ul>
    <li>
      ประสบการณ์การพัฒนาสแต็กเต็มรูปแบบ 2-5 ปี โดยควรจะอยู่ในรูปแบบที่สมจริงหรือ
ระบบแบบโต้ตอบ
    </li>
    <li>ทักษะที่แข็งแกร่งใน JavaScript/TypeScript, Node.js, React, และ API</li>
    <li>
      ความชำนาญด้านกรอบการพัฒนา XR (Unity, Unreal, WebXR) เป็นสิ่งที่มีค่าอย่างมาก
    </li>
    <li>
      คุ้นเคยกับบริการคลาวด์ (AWS, Firebase, Azure) สำหรับการจัดการข้อมูลแบบเรียลไทม์
    </li>
    <li>
      ผู้แก้ปัญหาแบบร่วมมือที่รักการผสานการออกแบบ เทคโนโลยี และการเล่าเรื่อง
    </li>
  </ul>
</CareerItem>

<CareerItem title="ทำไมต้องเข้าร่วม OBRIVE?">
  <ul>
    <li>
      สร้างอนาคต: ทำงานบนผลิตภัณฑ์ชั้นนำ เช่น Obpark (การนำทาง AR) และ Obnest (อสังหาริมทรัพย์ XR)
    </li>
    <li>
      ผลกระทบข้ามอุตสาหกรรม: โครงการต่าง ๆ ในอุตสาหกรรมยานยนต์ อสังหาริมทรัพย์ ค้าปลีก การดูแลสุขภาพ และการศึกษา
    </li>
    <li>
      วัฒนธรรมแห่งนวัตกรรม: ราบเรียบ ครอบคลุม และออกแบบเพื่อความร่วมมือ
    </li>
    <li>
      เรียนรู้และเติบโต: เวิร์กช็อปประจำ โปรแกรมที่ปรึกษา และห้องทดลองการทดลอง
    </li>
  </ul>
</CareerItem>

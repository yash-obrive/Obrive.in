<CareerSection title="เกี่ยวกับบทบาทนี้">
<CareerItem>ในฐานะนักพัฒนา AR/VR/MR ที่ Obrive Industries คุณจะสร้างโซลูชันเสมือนจริงรุ่นต่อไปในด้านความเป็นจริงเสริม ความเป็นจริงเสมือน และความเป็นจริงผสม ผลงานของคุณจะขับเคลื่อนประสบการณ์เช่น Obpark (การนำทางรถยนต์อัจฉริยะด้วย AR) และ Obnest (แพลตฟอร์มอสังหาริมทรัพย์ XR) ช่วยกำหนดวิธีที่ธุรกิจและผู้บริโภคมีปฏิสัมพันธ์กับการประมวลผลเชิงพื้นที่</CareerItem>

<CareerItem title="สิ่งที่คุณจะทำ">
  <ul>
    <li>
      ออกแบบและพัฒนาแอปพลิเคชันที่ดื่มด่ำโดยใช้เอนจินเช่น Unity หรือ Unreal Engine
    </li>
    <li>
      ดำเนินการฟังก์ชัน AR/VR/MR บนแพลตฟอร์มมือถือ, หูฟัง, และการประมวลผลเชิงพื้นที่
    </li>
    <li>
      ร่วมมือกับนักออกแบบ UX/UI ศิลปิน 3 มิติ และนักวางกลยุทธ์ผลิตภัณฑ์เพื่อมอบประสบการณ์แบบดื่มด่ำที่ราบรื่น
    </li>
    <li>
      ปรับประสิทธิภาพแอปเพื่อประสิทธิภาพ ความสามารถในการใช้งาน และข้ามแพลตฟอร์ม
ความเข้ากันได้
    </li>
    <li>
      ผสานรวมเซ็นเซอร์ที่สวมใส่ได้ ข้อมูลเชิงพื้นที่ และการทําแผนที่สิ่งแวดล้อมสําหรับ
ความสมจริงที่เพิ่มขึ้น
    </li>
    <li>
      เข้าร่วมการทำงานแบบอไจล์—การสาธิตสปรินต์ การวิจารณ์ UX และเวิร์กช็อป MR/VR—เพื่อพัฒนาฟีเจอร์ของผลิตภัณฑ์อย่างรวดเร็ว
    </li>
  </ul>
</CareerItem>

<CareerItem title="เกี่ยวกับคุณ">
  <ul>
    <li>
      มีประสบการณ์ 2-5 ปีในการพัฒนา AR/VR/MR พร้อมความเข้าใจที่มั่นคงเกี่ยวกับ Unity, Unreal Engine หรือแพลตฟอร์มที่คล้ายกัน
    </li>
    <li>
      ความชำนาญในภาษา C#, C++ หรือภาษาอื่นที่คล้ายกันสำหรับการสร้างแอปพลิเคชันเชิงโต้ตอบ
    </li>
    <li>
      มีประสบการณ์การใช้งานจริงกับ AR SDKs (ARCore, ARKit, Vuforia) หรือชุดหูฟัง VR (Meta Quest, HoloLens เป็นต้น)
    </li>
    <li>
      ความคุ้นเคยกับแนวคิดการประมวลผลเชิงพื้นที่—การเข้าใจฉาก, SLAM, การบดบัง, การติดตามท่าทาง
    </li>
    <li>
      หลงใหลในการเล่าเรื่องผ่านอินเทอร์เฟซแบบดื่มด่ำและมีความละเอียดอ่อนต่อแนวปฏิบัติ UX ที่ดีที่สุด
    </li>
    <li>
      การสื่อสารที่ยอดเยี่ยม ความเข้าอกเข้าใจ และแนวคิดการทำงานร่วมกันเพื่อการมีส่วนร่วมอย่างจริงจังในทีมข้ามสายงาน
    </li>
  </ul>
</CareerItem>

<CareerSection title="เกี่ยวกับบทบาทนี้">
<CareerItem>ในฐานะผู้จัดการผลิตภัณฑ์สำหรับโซลูชัน AR/VR คุณจะนำวิสัยทัศน์เชิงกลยุทธ์ แผนงาน และการดำเนินการของผลิตภัณฑ์เชิงปฏิสัมพันธ์ของ Obrive คุณจะทำงานข้ามทีมฟังก์ชันต่างๆ—การออกแบบ วิศวกรรม การตลาด—เพื่อกำหนด เปิดตัว และขยายผลิตภัณฑ์ เช่น Obpark (การนำทาง AR) และ Obnest (แพลตฟอร์มอสังหาริมทรัพย์ XR) ซึ่งมอบคุณค่าในโลกจริงผ่านเทคโนโลยีเชิงปฏิสัมพันธ์</CareerItem>

<CareerItem title="สิ่งที่คุณจะทำ">
  <ul>
    <li>
      กำหนดกลยุทธ์ผลิตภัณฑ์ วิสัยทัศน์ และแผนงานที่เน้นประสบการณ์ AR, VR, MR และการประมวลผลเชิงพื้นที่
    </li>
    <li>
      ทำงานร่วมกับนักออกแบบ UX วิศวกร และฝ่ายการตลาดเพื่อแปลงข้อมูลเชิงลึกของลูกค้าให้เป็นคุณสมบัติของผลิตภัณฑ์
    </li>
    <li>
      นำการวิจัยตลาดและการวิเคราะห์การแข่งขันเพื่อชี้นำการจัดลำดับความสำคัญของคุณสมบัติและการวางตำแหน่งผลิตภัณฑ์
    </li>
    <li>
      ขับเคลื่อนรอบการพัฒนาที่ว่องไว ติดตามตัวชี้วัดผลิตภัณฑ์ และปรับปรุงตามข้อเสนอแนะของผู้ใช้และการวิเคราะห์
    </li>
    <li>
      ทำหน้าที่เป็นนักส่งเสริมผลิตภัณฑ์—เขียนเอกสารสรุป จัดการสาธิต และพูดในงานลูกค้าหรืองานอุตสาหกรรม
    </li>
  </ul>
</CareerItem>

<CareerItem title="เกี่ยวกับคุณ">
  <ul>
    <li>
      มีประสบการณ์ด้านการจัดการผลิตภัณฑ์มากกว่า 3 ปีในบริษัทเทคโนโลยี พร้อมความชื่นชอบในเทคโนโลยีเชิงลึก
    </li>
    <li>
      ความเข้าใจอย่างลึกซึ้งในแพลตฟอร์ม AR, VR, MR แนวโน้มการคำนวณเชิงพื้นที่ที่เกิดขึ้นใหม่ และกลยุทธ์การเข้าสู่ตลาด
    </li>
    <li>
      มีความสามารถในการขับเคลื่อนการส่งมอบผลิตภัณฑ์ตั้งแต่แนวคิดจนถึงการเปิดตัวในสภาพแวดล้อมแบบ Agile
    </li>
    <li>
      ทักษะการสื่อสาร การบริหารผู้มีส่วนได้ส่วนเสีย และการจัดลำดับความสำคัญที่ยอดเยี่ยม
    </li>
    <li>
      ความกระตือรือร้นด้านเทคโนโลยีเสมือนจริง ผลกระทบทางการค้า และการมอบประสบการณ์ผู้ใช้ที่มีความหมาย
    </li>
  </ul>
</CareerItem>

<CareerItem title="ทำไมต้องเข้าร่วม OBRIVE?">
  <ul>
    <li>
      เป็นผู้นำด้านนวัตกรรม: สร้างผลิตภัณฑ์ AR/VR รุ่นต่อไปที่เปลี่ยนแปลงอุตสาหกรรมเช่น อสังหาริมทรัพย์ ยานยนต์ การดูแลสุขภาพ และธุรกิจองค์กร
    </li>
    <li>
      อิทธิพลข้ามสายงาน: ร่วมมือกับนักออกแบบ วิศวกร ศิลปินเคลื่อนไหว และผู้เชี่ยวชาญด้านพื้นที่ในวัฒนธรรมที่ราบเรียบและมีความรวมถึงทุกคน
    </li>
    <li>
      สภาพแวดล้อมการทำงานที่มีความยืดหยุ่น: รูปแบบการทำงานที่ยืดหยุ่น รองรับการทำงานระยะไกล พร้อมการร่วมมือแบบตัวต่อตัวเป็นประจำที่เมืองบังกาลอร์
    </li>
    <li>
      การเติบโตและการยอมรับ: โอกาสในการเป็นผู้นำวิสัยทัศน์ผลิตภัณฑ์ในบริษัทเทคโนโลยีเสมือนจริงที่มีผลกระทบสูงและเติบโตอย่างรวดเร็ว
    </li>
  </ul>
</CareerItem>

<FAQAccordionSection title="ข้อมูลทั่วไป">
  <FAQItem question="What are Obpark, Obnest, Obnavi, and Obmove?">
    <ul>
      <li>
Obpark คือระบบบริหารจัดการทรัพย์สินเชิงพื้นที่ที่สามารถสร้างประสบการณ์ 3 มิติได้
การนำทางในคลังสินค้า หรือสถานที่
      </li>
      <li>
Obnest มอบสภาพแวดล้อมการฝึกอบรมเชิงลึกที่ปรับให้เหมาะสม—เหมาะสำหรับ
การปฐมนิเทศ, การจำลองสถานการณ์, และการซ้อมความปลอดภัย
      </li>
      <li>
Obnavi ช่วยให้การซ้อนแผนที่นำทาง AR ที่รับรู้บริบทสำหรับวิทยาเขต
โรงงานผลิต หรือสถานที่ค้าปลีก
      </li>
      <li>
Obmove มอบแอปพลิเคชันเชิงโต้ตอบแบบท่าทางใน AR/VR/MR
สภาพแวดล้อม—ออกแบบมาสำหรับการประกอบ ดูแลรักษา หรือการฝึกอบรมแบบลงมือทำ
      </li>
    </ul>
  </FAQItem>
  <FAQItem question="Who uses these products?">
ชุดเทคโนโลยีเชิงโต้ตอบของ Obrive ให้บริการอุตสาหกรรมต่าง ๆ เช่น การผลิต และอสังหาริมทรัพย์
การดูแลสุขภาพ โลจิสติกส์ การศึกษา และอื่นๆ—ขยายจากสถานที่เดียว
การนำไปใช้จนถึงการปรับใช้ทั่วทั้งองค์กร
  </FAQItem>
</FAQAccordionSection>

<FAQAccordionSection title="คุณสมบัติของผลิตภัณฑ์">
  <FAQItem question="What are the key features across Obrive's product suite?">
    <ul>
      <li>
การส่งมอบประสบการณ์เสมือนจริง—ปรับใช้งาน AR, VR, MR และแอปพลิเคชันเชิงพื้นที่ทั่วทั้ง
หูฟังและอุปกรณ์มือถือ
      </li>
      <li>
พอร์ทัลดูตัวอย่างอย่างปลอดภัย—แชร์เดโมแบบสมจริงทันทีผ่านช่องทางที่ปลอดภัย,
อินเทอร์เฟซเบราว์เซอร์ที่มีแบรนด์—ไม่ต้องติดตั้ง
      </li>
      <li>
คลังสินทรัพย์ 3 มิติ—จัดเก็บ แท็ก และนำสินทรัพย์เสมือนจริงไปใช้ซ้ำในโครงการต่างๆ
      </li>
      <li>
การวิเคราะห์และพรอมต์ปรับตัว—ติดตามการมีส่วนร่วมของผู้ใช้ รูปแบบการคลิก,
และการไหลของเซสชัน; ส่งคำกระตุ้นแบบเรียลไทม์
      </li>
      <li>
เวิร์กโฟลว์และแบรนดิ้งแบบกำหนดเอง—กำหนดค่าผลิตภัณฑ์แต่ละชิ้นด้วยของบริษัทของคุณ
อัตลักษณ์ภาพและตรรกะการดำเนินงาน
      </li>
      <li>
API การรวมระบบ—ซิงค์กับแพลตฟอร์ม LMS, CRM, ERP, IoT และ CAD สำหรับ
การแลกเปลี่ยนข้อมูลอย่างราบรื่น
      </li>
    </ul>
  </FAQItem>
  <FAQItem question="How does Obpark manage 3D spatial navigation data?">
Obpark รองรับการทำแผนที่ทรัพย์สินและชั้นการสอบถามเชิงพื้นที่—ช่วยให้ผู้ใช้สามารถ
ระบุวัตถุหรือโซนภายในสภาพแวดล้อม 3 มิติแบบโต้ตอบ ระบบ
ช่วยให้การจัดการและการเรียกคืนพื้นที่ทางกายภาพเสมือนมีประสิทธิภาพ
  </FAQItem>
</FAQAccordionSection>

หรือการนำทางแบบไดนามิกในพื้นที่ซับซ้อนผ่าน Obnavi แต่ละผลิตภัณฑ์คือ
ออกแบบมาสำหรับการปรับแต่งอย่างยืดหยุ่นให้เข้ากับสภาพแวดล้อมและการเรียนรู้ของคุณ
เป้าหมาย
  </FAQItem>

แก้ไข → เปิดตัว ลดเวลาการติดตั้งและปรับความเห็นของผู้มีส่วนได้ส่วนเสียให้สอดคล้องกับ
กรอบเวลาการผลิต
  </FAQItem>

วัฏจักร—เพื่อให้มั่นใจถึงความร่วมมือที่ราบรื่นและโปร่งใสในทุกสถานที่
  </FAQItem>

อัตรา คำสั่งเสียงหรือท่าทางที่ใช้ และอื่นๆ ทั้งหมดสามารถเข้าถึงได้สำหรับ

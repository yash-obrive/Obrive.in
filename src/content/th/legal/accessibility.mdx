<br />
เราพัฒนาโซลูชัน AR, VR, MR, XR และการประมวลผลเชิงพื้นที่ของเราให้ครอบคลุม ใช้งานง่าย และปรับตัวได้ เพื่อให้คนทุกความสามารถสามารถได้รับประโยชน์จากเทคโนโลยีเสมือนจริง
</CompanyInfoItem>

<CompanyInfoItem>
<ul>

            <li>การทดสอบและการปรับปรุงอย่างต่อเนื่อง</li>

          </ul>

อย่างจริงจังเมื่อเรากําหนดอนาคตของเทคโนโลยีแบบสมจริง

  </CompanyInfoItem>
</CompanyInfoSection>

<CompanyInfoSection>
  <CompanyInfoItem title="ความมุ่งมั่นของเรา">

      </li>
      <li>
        เรามีการออกแบบโดยคำนึงถึงมาตรฐานการเข้าถึงแบบสากล โดยนำแนวทางปฏิบัติที่ดีที่สุดจาก WCAG 2.1 แนวทาง ADA และกรอบการเข้าถึงแบบดื่มด่ำมาใช้
      </li>
      <li>
        การเข้าถึงถูกสร้างขึ้นมาในกระบวนการออกแบบและพัฒนาของเรา ไม่ใช่ถูกมองข้ามเป็นเรื่องรองทีหลัง
      </li>
    </ul>
  </CompanyInfoItem>
</CompanyInfoSection>

<CompanyInfoSection title="วิธีที่เราสนับสนุนการเข้าถึง">
<CompanyInfoItem title="1. ความเข้ากันได้กับเทคโนโลยีช่วยเหลือ">
<ul>
            <li>
              แพลตฟอร์มและพอร์ทัลเว็บของเราทำงานร่วมกับโปรแกรมอ่านหน้าจอ เครื่องมือจดจำเสียง และอุปกรณ์นำทางทางเลือกได้
            </li>
            <li>
              ประสบการณ์ VR และ AR ถูกออกแบบด้วยคำบรรยายเสียง คำบรรยายภาพ และอินเทอร์เฟซที่ปรับแต่งได้เมื่อเป็นไปได้
            </li>
          </ul>
</CompanyInfoItem>

<CompanyInfoItem title="2. การออกแบบเชิงดื่มด่ำแบบครอบคลุม">
  <ul>
    <li>
      การโต้ตอบด้วยการเคลื่อนไหวและท่าทางใน Obmove รวมถึงทางเลือกสำหรับผู้ใช้ที่มีความสามารถในการเคลื่อนไหวจำกัด
    </li>
    <li>การนำทาง AR ใน Obnavi มีสัญญาณหลายประสาทสัมผัส (ภาพ + เสียง)</li>
    <li>
      สภาพแวดล้อม VR ใน Obnest สามารถปรับแต่งได้ด้วยการนำทางที่เรียบง่ายและโหมดแนะนำ
    </li>
  </ul>
</CompanyInfoItem>

<CompanyInfoItem title="3. ประสบการณ์ผู้ใช้ที่ปรับแต่งได้">
  <ul>
    <li>
      ตัวเลือกสำหรับการปรับขนาดข้อความ โหมดความคมชัดสูง การตอบสนองแบบสั่น และคำบรรยาย
    </li>
    <li>ค่าการตั้งค่าของผู้ใช้จะถูกบันทึกเพื่อความสอดคล้องในแต่ละเซสชัน</li>
  </ul>
</CompanyInfoItem>

<CompanyInfoItem title="4. การทดสอบและข้อเสนอแนะอย่างต่อเนื่อง">
<ul>
            <li>
              มีการตรวจสอบการเข้าถึงอย่างสม่ำเสมอในเว็บไซต์ พอร์ทัล AR/VR และแอปเชิงพื้นที่
            </li>
            <li>
              เราขอเชิญผู้ใช้แสดงความคิดเห็นเพื่อระบุอุปสรรคและปรับปรุงคุณสมบัติการเข้าถึง
            </li>
          </ul>
</CompanyInfoItem>
</CompanyInfoSection>

<CompanyInfoSection title="มาตรฐานการเข้าถึงที่เราปฏิบัติตาม">
  <CompanyInfoItem>
    <ul>
      <li>แนวทางการเข้าถึงเนื้อหาเว็บ (WCAG 2.1 ระดับ AA)</li>
      <li>ความสอดคล้องตามมาตรา 508 (สหรัฐอเมริกา)</li>
      <li>มาตรฐานความเข้าถึงตาม ADA (พระราชบัญญัติคนพิการของสหรัฐอเมริกา)</li>
      <li>แนวปฏิบัติการออกแบบแบบครอบคลุมสำหรับเทคโนโลยีดื่มด่ำ</li>
    </ul>
  </CompanyInfoItem>
</CompanyInfoSection>

  </CompanyInfoItem>

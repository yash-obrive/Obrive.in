  </CompanyInfoItem>
</CompanyInfoSection>

      <li>

      </li>
      <li>
        ค่าธรรมเนียมและการชำระเงิน: กำหนดข้อกำหนดการชำระเงิน การต่ออายุ และโครงสร้างการออกใบแจ้งหนี้
      </li>
      <li>
        ทรัพย์สินทางปัญญา: ลูกค้าคงสิทธิ์ความเป็นเจ้าของเนื้อหาของตน Obrive คงสิทธิ์ความเป็นเจ้าของแพลตฟอร์ม
      </li>
      <li>
        ความลับ: การปกป้องข้อมูลธุรกิจและโครงการที่ละเอียดอ่อนร่วมกัน
      </li>
      <li>
        การสนับสนุนและการรับประกัน: ระดับการให้บริการ เวลาใช้งาน และข้อผูกพันในการสนับสนุนด้านเทคนิค
      </li>
      <li>

      </li>
    </ul>

  </CompanyInfoItem>

<CompanyInfoSection title="ข้อตกลงการให้บริการหลัก (MSA) อย่างละเอียด">
  <CompanyInfoItem>
    สัญญาบริการหลักนี้ (MSA) ควบคุมความสัมพันธ์ระหว่าง Obrive Industries Pvt. Ltd. ("Obrive," "เรา" หรือ "พวกเรา") และลูกค้าของบริษัท ("ลูกค้า," "คุณ" หรือ "ของคุณ") สำหรับบริการเทคโนโลยีเชิงโต้ตอบรวมถึง AR, VR, MR, XR, การออกแบบ 3D และโซลูชันการประมวลผลเชิงพื้นที่
  </CompanyInfoItem>
</CompanyInfoSection>
<CompanyInfoSection title="1. ขอบเขตของบริการ">
  <CompanyInfoItem>
    <ul>
      <li>
        Obrive จะจัดหาโซลูชัน ผลิตภัณฑ์ แอปพลิเคชัน และบริการวิชาชีพตามที่ตกลงไว้ในเอกสารสัญญาการทำงาน (SOW)
      </li>
      <li>
        แต่ละ SOW จะกำหนดผลลัพธ์ของโครงการ จุดสังเกตเกณฑ์การยอมรับ และระยะเวลาการปรับใช้งาน
      </li>
      <li>
        บริการอาจรวมถึงการให้คำปรึกษา การสร้างแบบจำลอง 3 มิติ การพัฒนาแอปพลิเคชัน การรวมระบบ การฝึกอบรม และการสนับสนุนทางเทคนิค
      </li>
    </ul>
  </CompanyInfoItem>
</CompanyInfoSection>

<CompanyInfoSection title="2. ค่าธรรมเนียมและการชำระเงิน">
  <CompanyInfoItem>
    <ul>
      <li>ค่าธรรมเนียมจะถูกระบุไว้ในแต่ละ SOW หรือแบบฟอร์มคำสั่งซื้อ</li>
      <li>
        เงื่อนไขการชำระเงิน: โดยปกติภายใน 10 วันถัดไปจากวันที่ออกใบแจ้งหนี้ เว้นแต่จะระบุไว้เป็นอย่างอื่น
      </li>
      <li>การชำระเงินล่าช้าอาจทำให้บริการถูกระงับหรือเกิดค่าดอกเบี้ย</li>
      <li>
        บริการที่เกิดซ้ำ (โฮสติ้ง การสนับสนุน การบำรุงรักษา) จะถูกเรียกเก็บเงินตามรูปแบบการสมัครสมาชิก
      </li>
    </ul>
  </CompanyInfoItem>
</CompanyInfoSection>

<CompanyInfoSection title="3. สิทธิในทรัพย์สินทางปัญญา">
  <CompanyInfoItem>
    <ul>
      <li>
        เนื้อหาของลูกค้า: ลูกค้ายังคงถือกรรมสิทธิ์ในข้อมูลแบบเฉพาะตัว โมเดล และทรัพย์สินทั้งหมดที่พวกเขาจัดหาให้
      </li>
      <li>
        ทรัพย์สินทางปัญญาของ Obrive: Obrive ยังคงถือกรรมสิทธิ์ในแพลตฟอร์มเสมือนจริง โมดูลที่สร้างไว้ล่วงหน้า SDK API และโครงสร้างพื้นฐานของตน
      </li>
      <li>
        งานที่จัดทำตามคำสั่ง: เว้นแต่จะมีข้อตกลงอื่น การพัฒนาตามคำสั่งอาจมอบสิทธิ์ให้กับลูกค้าในการใช้งานภายในแบบไม่เฉพาะตัวและไม่สามารถโอนสิทธิ์ได้
      </li>
    </ul>
  </CompanyInfoItem>
</CompanyInfoSection>

<CompanyInfoSection title="4. การเก็บรักษาความลับ">
  <CompanyInfoItem>
    <ul>
      <li>
        ทั้งสองฝ่ายตกลงที่จะรักษาความลับของข้อมูลทางธุรกิจ การเงิน และเทคนิคที่สำคัญ
      </li>
      <li>
        ข้อมูลที่เป็นความลับจะไม่ถูกเปิดเผยต่อบุคคลที่สามโดยไม่ได้รับความยินยอมเป็นลายลักษณ์อักษร ยกเว้นตามที่กฎหมายกำหนด
      </li>
      <li>
        ข้อผูกมัดในการรักษาความลับมีผลต่อเนื่องเป็นเวลา 3 ปีหลังจากการสิ้นสุดของข้อตกลง
      </li>
    </ul>
  </CompanyInfoItem>
</CompanyInfoSection>

<CompanyInfoSection title="5. การปกป้องข้อมูลและความปลอดภัย">
  <CompanyInfoItem>
    <ul>
      <li>
        Obrive มุ่งมั่นที่จะดำเนินมาตรการปกป้องข้อมูลตามมาตรฐานอุตสาหกรรม (การเข้ารหัส การควบคุมการเข้าถึง การสำรองข้อมูล)
      </li>
      <li>
        การปฏิบัติตามข้อกำหนดการคุ้มครองข้อมูลที่บังคับใช้ (GDPR, CCPA, ฯลฯ) ตามที่จำเป็น
      </li>
      <li>
        ลูกค้ายังคงต้องรับผิดชอบในการรับรองการใช้งานข้อมูลของตนอย่างถูกกฎหมายภายในระบบของ Obrive
      </li>
    </ul>
  </CompanyInfoItem>
</CompanyInfoSection>

<CompanyInfoSection title="6. การรับประกันและข้อจำกัดความรับผิด">
  <CompanyInfoItem>
    <ul>
      <li>
        Obrive รับประกันว่าบริการจะถูกดำเนินการอย่างมืออาชีพและสอดคล้องกับมาตรฐานของอุตสาหกรรม
      </li>
      <li>
        ไม่มีการรับประกันว่าบริการจะไม่ถูกขัดจังหวะหรือปราศจากข้อผิดพลาด
      </li>
      <li>
        ปฏิเสธความรับผิดชอบต่อการรวมระบบของบุคคลที่สามที่อยู่นอกการควบคุมของ Obrive
      </li>
    </ul>
  </CompanyInfoItem>
</CompanyInfoSection>

<CompanyInfoSection title="7. ระดับการสนับสนุนและบริการ">
  <CompanyInfoItem>
    <ul>
      <li>
        Obrive จะให้การสนับสนุนทางเทคนิคตามที่ระบุไว้ใน SOW หรือข้อตกลงระดับการให้บริการ (SLA)
      </li>
      <li>รวมถึงการแก้ไขข้อบกพร่อง การอัปเดต และการปรับปรุงเป็นระยะ</li>
      <li>เวลาตอบสนองจะแตกต่างกันไปขึ้นอยู่กับความรุนแรงและผลกระทบของปัญหา</li>
    </ul>
  </CompanyInfoItem>
</CompanyInfoSection>

<CompanyInfoSection title="8. ระยะเวลาและการยกเลิก">

      <li>
        ฝ่ายใดฝ่ายหนึ่งสามารถยกเลิกได้โดยแจ้งเป็นลายลักษณ์อักษรล่วงหน้า 30 วันเพื่อความสะดวก
      </li>
      <li>
        สามารถยกเลิกได้ทันทีในกรณีละเมิด ล้มละลาย หรือไม่ชำระเงิน
      </li>
      <li>
        เมื่อสิ้นสุดสัญญา ลูกค้าต้องหยุดใช้เทคโนโลยีของ Obrive และชำระเงินค้างชำระทั้งหมด
      </li>
    </ul>
  </CompanyInfoItem>
</CompanyInfoSection>

<CompanyInfoSection title="9. ความรับผิดชอบและการชดใช้ค่าเสียหาย">

    <ul>
      <li>
        ความรับผิดชอบของ Obrive จำกัดอยู่ที่จำนวนเงินที่ลูกค้าได้ชำระใน 12 เดือนที่ผ่านมา
      </li>
      <li>
        ไม่มีฝ่ายใดต้องรับผิดชอบต่อความเสียหายทางอ้อม บังเอิญ หรือเป็นผลตามมา
      </li>
      <li>
        แต่ละฝ่ายตกลงที่จะชดใช้ค่าเสียหายให้แก่กันและกันต่อข้อเรียกร้องจากบุคคลที่สามที่เกิดจากการใช้ผิด, การละเมิดทรัพย์สินทางปัญญา หรือการละเมิดข้อกำหนด.
      </li>
    </ul>
  </CompanyInfoItem>

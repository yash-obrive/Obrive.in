<CareerSection title="关于此职位">
<CareerItem>在Obrive Industries，市场与内容专家——沉浸式技术将围绕我们的一系列沉浸式技术（涵盖增强现实、虚拟现实、混合现实、3D设计和空间计算）打造引人入胜、信息丰富且与品牌一致的叙事内容。你将通过讲故事的方式让我们的创新成果栩栩如生，激发想象力、教育受众，并推动各平台的互动参与。</CareerItem>

<CareerItem title="你将做什么">
  <ul>
    <li>
      开发博客、案例研究、社交媒体内容和视频脚本，展示像 Obpark 和 Obnest 这样的沉浸式项目。
    </li>
    <li>
      与设计师和工程师合作，制作引人注目的营销视觉效果和动态图形
    </li>
    <li>
      规划并实施SEO策略、数字营销活动和分析，以推动品牌知名度和转化率
    </li>
    <li>
      管理电子邮件营销、网络研讨会以及展示沉浸式技术趋势的网络研讨会
    </li>
    <li>
      在所有营销接触点和渠道中保持品牌一致性和信息传达
    </li>
  </ul>
</CareerItem>

<CareerItem title="关于你">
  <ul>
    <li>
      具备出色的写作和讲故事能力，并在科技或B2B营销方面有经验。
    </li>
    <li>
      熟悉沉浸式技术术语、工作流程或使用案例。
    </li>
    <li>
      精通SEO工具、内容策略和绩效追踪（例如Google Analytics）。
    </li>
    <li>
      积极主动、有创造力，并渴望通过引人入胜的内容解释复杂的想法。
    </li>
    <li>
      能够自如地与产品、创意和业务团队进行跨职能合作。
    </li>
  </ul>
</CareerItem>

<CareerItem title="为什么加入OBRIVE？">
  <ul>
    <li>
      塑造叙事：以激发现实世界采纳的方式讲述 AR、VR、MR 和空间计算的故事
    </li>
    <li>
      与创新者合作：支持开发者、设计师和产品负责人，在他们推动沉浸式技术边界的过程中
    </li>
    <li>
      灵活的工作方式：在班加罗尔接受混合或远程工作，同时享有协作时刻
    </li>
    <li>

    </li>
  </ul>
</CareerItem>

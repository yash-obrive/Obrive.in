<CareerSection title="关于此职位">
<CareerItem>作为一名3D可视化设计师，你将创建栩栩如生、逼真的3D模型和环境，使我们的沉浸式平台栩栩如生——涵盖增强现实（AR）、虚拟现实（VR）、混合现实（MR）和空间计算体验。你的工作将是旗舰产品的核心，如Obpark（AR导航）和Obnest（XR家庭导览）。</CareerItem>

<CareerItem title="你将做什么">
  <ul>
    <li>为沉浸式应用制作高度详细的3D资产。</li>
    <li>
      构建逼真的建筑可视化、产品原型以及互动式 AR/VR 漫游。
    </li>
    <li>
      与开发人员、UX/UI设计师和产品策略师合作，将3D模型整合到现实世界的体验中。
    </li>
    <li>
      优化资源以在各设备上平衡视觉保真度与实时性能。
    </li>
    <li>
      通过纹理、照明和动态建模推动视觉美学和创新。
    </li>
  </ul>
</CareerItem>

<CareerItem title="关于你">
  <ul>
    <li>
      精通如 Blender、Maya、3ds Max 或 Cinema 4D 等 3D 工具。
    </li>
    <li>
      对逼真渲染（PBR）、光照和材质工作流程有深入理解。
    </li>
    <li>
      展示沉浸式 3D 可视化或建筑效果图的作品集。
    </li>
    <li>在增强现实、虚拟现实或混合现实平台上优化资源的经验。</li>
    <li>
      对细节的出色关注以及通过沉浸式设计进行视觉叙事的热情。
    </li>
  </ul>
</CareerItem>

<CareerSection title="关于此职位">
<CareerItem>作为Obrive Industries的AR/VR/MR开发人员，您将构建跨增强现实、虚拟现实和混合现实的下一代沉浸式解决方案。您的创作将驱动诸如Obpark（AR智能汽车导航）和Obnest（XR房地产平台）之类的体验，帮助塑造企业和消费者与空间计算互动的方式。</CareerItem>

<CareerItem title="你将做什么">
  <ul>
    <li>
      使用像 Unity 或 Unreal Engine 这样的引擎设计和开发沉浸式应用程序。
    </li>
    <li>
      在移动设备、头戴设备和空间计算平台上实现 AR/VR/MR 功能。
    </li>
    <li>
      与 UX/UI 设计师、3D 艺术家和产品策略师合作，提供无缝的沉浸式体验。
    </li>
    <li>
      优化应用程序的性能、可用性和跨平台兼容性。
    </li>
    <li>
      整合可穿戴传感器、空间数据和环境映射，以增强现实感。
    </li>
    <li>
      参与敏捷工作流程——冲刺演示、用户体验评审以及混合现实/虚拟现实研讨会——以快速发展产品功能。
    </li>
  </ul>
</CareerItem>

<CareerItem title="关于你">
  <ul>
    <li>
      2-5 年 AR/VR/MR 开发经验，熟练掌握 Unity、Unreal Engine 或类似平台。
    </li>
    <li>
      熟练掌握 C#、C++ 或其他可用于沉浸式应用开发的类似语言。
    </li>
    <li>
      具备使用 AR SDK（ARCore、ARKit、Vuforia）或 VR 头显（Meta Quest、HoloLens 等）的实际操作经验
    </li>
    <li>
      熟悉空间计算概念——场景理解、SLAM、遮挡、手势追踪。
    </li>
    <li>
      通过沉浸式界面讲故事的热情以及对用户体验最佳实践的敏感度。
    </li>
    <li>
      出色的沟通能力、同理心以及协作心态，能够积极参与跨职能团队。
    </li>
  </ul>
</CareerItem>

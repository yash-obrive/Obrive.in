Obnavi — 室内/室外空间增强现实导航系统
环境。
            </li>
            <li>
Obmove — 基于运动、手势和 XR 的互动解决方案。
            </li>
          </ul>
</CompanyInfoItem>

<CompanyInfoItem title="主要亮点：">
<br />
<ul>
            <li>
使用权：客户获得使用Obrive产品的许可，条件是
合同中概述。
            </li>
            <li>
限制：禁止转售、逆向工程或未经授权
分布。
            </li>
            <li>
数据与安全：客户仍然对上传的数据负责；
Obrive 保护平台安全。
            </li>
            <li>
更新和支持：Obrive提供更新，错误修复和
根据订阅条款提供技术支持。
            </li>
            <li>
终止：如果违反条款或
协议到期。
            </li>
          </ul>
<br />
这些特定于产品的条款确保了清晰性、合规性以及顺利运行
使用Obrive技术的行业。

<CompanyInfoSection title="产品协议的详细条款">
<CompanyInfoItem>
本产品协议条款管辖Obrive Industries的使用
沉浸式技术平台和解决方案，包括Obpark,
Obnest，Obnavi和Obmove。
</CompanyInfoItem>

<CompanyInfoItem title="1. 协议范围">
本协议专门适用于Obrive旗下的每一款产品
工业。 通过使用我们的平台，您同意遵守这些
与我们的主服务协议一起的特定于产品的条款。
</CompanyInfoItem>
</CompanyInfoSection>

<CompanyInfoSection title="产品使用条款">
<CompanyInfoItem title="a. Obpark（增强现实/混合现实停车导航应用）">
<ul>
            <li>
专为停车管理、导航和智能出行设计。
            </li>
            <li>
客户可以将 Obpark 部署用于内部操作和面向客户的业务
服务或企业集成。
            </li>
            <li>
禁止用于不相关行业的再利用（例如，
转售为单独的应用程序）。
            </li>
          </ul>
</CompanyInfoItem>

<CompanyInfoItem title="B.Obnest(MR/VR房地产导航平台)">
  <ul>
    <li>
实现身临其境的属性演练、建筑可视化和
客户演示。
    </li>
    <li>
获发牌照供地产发展商、经纪及物业使用
管理人员。
    </li>
    <li>
客户必须确保上传的3D资产、平面图和内容是
合法拥有/许可的。
    </li>
  </ul>
</CompanyInfoItem>

<CompanyInfoItem title="C.Obnavi（空间AR导航系统）">
  <ul>
    <li>
为校园、商场提供室内/室外AR导航复盖,
机场和制造工厂。
    </li>
    <li>
允许作为企业系统或客户服务的一部分使用。
    </li>
    <li>
未经事先许可，禁止在涉及公共安全的应用中使用
获得批准。
    </li>
  </ul>
</CompanyInfoItem>

<CompanyInfoItem title="d. Obmove（运动/XR 交互平台）">
<ul>
            <li>
提供基于手势的控制、XR 培训和动作
模拟。
            </li>
            <li>
获得培训、教育和企业生产力使用许可
案件。
            </li>
            <li>
不允许用于军事或国防相关用途，除非
明确收缩的。
            </li>
          </ul>
</CompanyInfoItem>
</CompanyInfoSection>
